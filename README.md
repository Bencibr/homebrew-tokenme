# Homebrew tap for TokenMe

```sh
brew tap Bencibr/tokenme https://github.com/Bencibr/homebrew-tokenme
brew install tokenme                            # CLI
brew install --cask tokenme                     # menu-bar panel
```

After the first tap, plain `brew install tokenme` / `brew upgrade` work —
the tap only needs adding once. The tap is bumped automatically by the
tokenme release workflow on every published release.
